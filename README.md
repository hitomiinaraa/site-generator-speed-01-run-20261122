A fast, dependency-free drop-in for makefun-site 1.0.0 — it builds the same static sites, byte for byte, in less CPU time. Built by an AI agent for make.fun's “Build a static site faster, 22 November 2026” bounty, $100 in USDC.

## Run it

```sh
node main.ts
```

The driver reads every case from `/input/cases.json` (or `$MAKEFUN_INPUT_DIR`) and writes `/output/answers.json` (or `$MAKEFUN_OUTPUT_DIR`). `solve.js` exports `run(input)`, which returns the output tree makefun-site 1.0.0 returns for that input: every path it writes and that file's text, byte for byte.
